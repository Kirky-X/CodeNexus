# 行为准则

## 我们的承诺

作为成员、贡献者和领导者，我们承诺让 CodeNexus 社区的参与体验对所有人来说都是无骚扰的，无论其年龄、体型、可见或不可见的残疾、族裔、性别特征、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、个人外貌、种族、宗教或性认同与取向如何。

我们承诺以有助于建设开放、友好、多元、包容和健康的社区的方式行事和互动。

## 我们的标准

有助于为社区营造积极环境的行为包括：

- 对他人表现出同理心和善意。
- 尊重不同的意见、观点和经历。
- 给予并坦然接受建设性反馈。
- 承担责任，向受错误影响的人道歉，并从中吸取教训。
- 关注不仅对我们个人、而且对整个社区最有利的事情。

不可接受的行为包括：

- 使用性化的语言或图像，以及任何形式的性关注或性暗示。
- 钓鱼、侮辱或贬低性评论，以及人身攻击或政治攻击。
- 公开或私下的骚扰。
- 未经明确许可，发布他人的私人信息（如住址或电子邮件地址）。
- 其他可被合理认定为在职业环境中不适当的行为。

## 执法职责

社区负责人负责阐明和执行本行为准则的标准，并将对其认为不适当、威胁性、冒犯性或有害的行为采取适当且公正的纠正措施。

社区负责人有权也有责任删除、编辑或拒绝不符合本行为准则的评论、提交、代码、Wiki 编辑、Issue 和其他贡献，并在适当时候说明审核决定的理由。

## 适用范围

本行为准则适用于所有社区空间，也适用于个人在公共场合正式代表社区的情况。代表社区的例子包括使用官方电子邮件地址、通过官方社交媒体账号发帖，或作为指定代表参与线上或线下活动。社区代表的具体定义可由社区负责人进一步阐明。

## 执法

如有辱骂、骚扰或其他不可接受的行为，可向负责执法的社区负责人（Kirky.X）报告，联系方式：**Kirky-X@outlook.com**。安全漏洞请走 GitHub [Security Advisories](https://github.com/Kirky-X/codenexus/security/policy) 私密披露通道（见 [安全文档](SECURITY.md)），不要通过公开渠道提交。所有投诉将被及时、公正的审查和调查。

所有社区负责人有义务尊重报告人的隐私和安全。具体执法政策的细则可另行发布。

## 执法指南

社区负责人将遵循以下社区影响指南来确定对违反本行为准则行为的后果：

### 1. 纠正

**社区影响**：使用不适当的语言或其他被视为不专业或不受欢迎的行为。

**后果**：社区负责人发出私下书面警告，明确违规性质并解释为何该行为不适当。可要求公开道歉。

### 2. 警告

**社区影响**：通过单次事件或一系列行为构成的违规。

**后果**：发出警告并附带对后续行为的后果说明。在指定时间内，不得与相关人员互动（包括主动联系执行本行为准则的人员），包括避免在社区空间以及社交媒体等外部渠道互动。违反此规定可能导致临时或永久封禁。

### 3. 临时封禁

**社区影响**：严重违反社区标准，包括持续的不适当行为。

**后果**：在指定时间内，禁止与社区进行任何形式的互动或公开沟通。在此期间，不得与相关人员互动（包括主动联系执行本行为准则的人员）。违反此规定可能导致永久封禁。

### 4. 永久封禁

**社区影响**：展现出一贯的违规模式，包括持续的不适当行为、骚扰个人，或攻击或贬低某类人群。

**后果**：永久禁止在社区内进行任何形式的公开互动。
